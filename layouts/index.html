go-icons

Free file-type icon sets as embedded SVG for pure-Go UIs — seti (Seti UI) and material (Material Icon Theme), each a data package that maps a file name to an SVG glyph and draws nothing.

CGO_ENABLED=0 Icon(filename) + Folder() embedded SVG via go:embed one repo per icon pack 100% coverage BSD-3 code · MIT artwork
Documentation GitHub

Toolkits that render their own UI need file-type icons, and the good free sets ship as loose SVG files with no Go packaging. go-icons closes that gap: each repo embeds a curated subset of one free, MIT-licensed icon set and exposes the same tiny contract — Icon(filename) returns the SVG document for a file (matched by exact base name, then by extension, then a generic-document fallback) and Folder() returns the folder glyph.

These are data packages: they return SVG strings and draw nothing. A renderer — such as go-widgets/toolkit's SVGIcon — turns the returned SVG into a drawn glyph. The Go code is BSD-3-Clause; the embedded artwork keeps its upstream MIT licence and is redistributed unmodified, with the original licence alongside it in each repo.
